# はじめに

本ガイドは、組み込み機器およびホスト上のアプリケーションを Mbed TLS から wolfSSL へ移行する開発者のためのものです。
移行に関わる主な設計上の違い、TLS クライアントの比較コード、実際の移行で頻繁に見られる落とし穴、そして API と設定の完全な対応表を収録しています。

## 対象読者

本ガイドは、Mbed TLS 3.6 または 4.x をベースにした製品を保守しており、wolfSSL への移行を計画・検討している C 言語開発者およびアーキテクトを対象としています。
現在お使いの製品で利用している Mbed TLS API についての知識を前提としています。

## 対象範囲

本ガイドは Mbed TLS 3.6 と 4.x の両方を対象とし、主に 4.x を基準として説明します。
TLS 層の API（`mbedtls_ssl_*`）は、暗号層に比べると 3.6 から 4.x への変更がはるかに少ないため、本ガイドの大部分は両バージョンに当てはまります。
両バージョンで異なる箇所については、本文中でその旨を明記しています。

本ガイドは TLS と DTLS を中心に扱います。
Mbed TLS や PSA Crypto の関数を直接呼び出しているコードは、ネイティブの wolfCrypt `wc_*` API へ移行することも、wolfPSA を介して wolfCrypt 上で PSA Crypto API をそのまま使い続けることもできます（[Mbed TLS にない機能](chapter06.md)を参照）。

## Mbed TLS のサポート状況

2026年10月時点の状況は次のとおりです。

| ブランチ | 状況 |
| -------------------- | -------------------------------------------------------------------------------- |
| 2.28 LTS | サポート終了。最終リリースは 2.28.10（2025年3月）。 |
| 3.6 LTS | 2027年3月までメンテナンス。最新リリースは 3.6.7（2026年7月）。 |
| 4.0 | 最初の 4.x リリース（2025年10月）。暗号機能は TF-PSA-Crypto 1.0 として分離。 |
| 4.1 LTS | 2029年3月まで修正提供予定と発表。最新リリースは 4.1.1（2026年7月）。 |
| 4.2 | 現行のメインラインリリース（2026年7月）。TF-PSA-Crypto 1.2 を使用。 |

2026年10月、Mbed TLS チームは、現在のメンテナが 2027年4月に TLS および X.509 ライブラリの開発から離れることを[発表](https://lists.trustedfirmware.org/archives/list/mbed-tls@lists.trustedfirmware.org/thread/YPIGCB7WN6GCHOGEGKOJXUYAP7OK527W/)しました。
新たなメンテナが引き継がない限り、これらのライブラリのセキュリティ修正とリリースはその時点で終了し、4.1 LTS ブランチの TLS および X.509 部分も影響を受けます。
なお、暗号層である TF-PSA-Crypto は引き続き活発にメンテナンスされます。

## 本ガイドの使い方

1. [設計上の違い](chapter02.md)を読み、変わる概念を把握します。
2. [TLS クライアントの移植](chapter03.md)と [API 対応表](chapter08.md)を参照しながら、TLS の初期設定と I/O のコードを移植します。
3. [設定オプションの対応](chapter09.md)をチェックリストとして使い、Mbed TLS の設定で使用している機能を有効にして wolfSSL をビルドします。
4. 移植したコードを[よくある落とし穴](chapter04.md)と照らし合わせて確認します。
   落とし穴の多くは、コンパイルは通るものの実行時に失敗するものです。
5. [はじめよう](chapter07.md)の説明に従い、既存の Mbed TLS の通信相手とのテストを行います。
