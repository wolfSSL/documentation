# サポート

wolfSSL は、Mbed TLS から移行するユーザー向けに複数のサポート窓口を用意しています。

## 商用サポート

wolfSSL Inc. は、wolfSSL のエンジニアリングチームに直接相談できる商用サポートパッケージを提供しています。
商用サポートでは次の内容に対応しています。

- 移行支援とコンサルティング
- FIPS 140-3 の導入に関するガイダンス
- カスタム機能の開発
- プラットフォームへの移植と統合

商用サポートおよびライセンスに関するお問い合わせは、wolfSSL までご連絡ください。

- 電子メール: [info@wolfssl.jp](mailto:info@wolfssl.jp)
- Web: [https://www.wolfssl.jp/contact/](https://www.wolfssl.jp/contact/)

wolfSSL では、ご購入前のサポートも無料で提供しています。
ご質問や問題がありましたら、サポートチームまで直接お問い合わせください。

- 電子メール: [support@wolfssl.com](mailto:support@wolfssl.com)（日本語可）
